## 2. 关键设计决定

### 2.1 block_id 由后端分配，模型不参与编号

`04` 第 5.1 节明确"block_id 由后端分配"。实现里模型只返回 `kind` / `text` /
`evidence_ids`，后端为每个 block 生成 UUID。测试用"模型自带上同一个 UUID"来验证
它确实被忽略——若采纳模型给出的 ID，全稿唯一性就取决于模型的自觉。

### 2.2 单节校验 + 全稿复核，缺一不可

每节各自通过校验，不代表拼起来仍合法：`block_id` 唯一性与 100 块总量都是**跨节**约束。
因此生成时先逐节校验（尽早发现坏输出），提交前再对五节整体跑一次 `validate_sections`。

### 2.3 失败不提交任何正文

任一节结构不合法、模板版本不符、空模型响应或坏引用，都直接失败，
**不创建 `ReviewRevision`**。`Review.latest_revision` 保持 `null`——
前端因此能区分"还没生成好"与"生成了一份正文"。部分章节只存在于任务中间产物。

2026-10-02 复核修复后，无相关证据的章节按 `04` 的覆盖限制规则生成合法 transition，
不再误报 PDF_PARSE_FAILED；仍须完成五节整体校验后才能提交正文。

### 2.4 人工改字不消除过时状态

`save_revision` 新版本**继承** base 的 `analysis_revision` 与 `corpus_revision`，
而不是写入当前 Run 的值。用户改几个字不会让上游已经过时的分析重新变新；
`ReviewRevisionSerializer.is_stale` 由"正文冻结的 revision vs Run 当前 revision"算出。

### 2.5 生成配置整段冻结

`Review.config_snapshot`（`review-gen-v2`）冻结生成模板与模型配置、实际内部检索限制、
扩展 / 重排模板和模型配置、章节查询与要求、总目标字数及分节目标、单节 block 上限，
**以及分析侧的 `config_snapshot`**（生成结果依赖的主题 / 争议 / 索引口径都在里面）。
冻结模板与当前模板不一致时显式失败，不用新模板冒充旧配置。
旧 v1 未完成综述没有完整的内部检索配置，不能用当前默认值补成“历史冻结输入”，应重新创建。
已有正文及历史编辑版本继续可读。

### 2.6 每节的检索查询必须短

`_section_query` 只取研究问题 + 节要求的**第一句**。第一版把整段节要求拼进查询，
结果召回直接落空：关键词覆盖率是 `命中词数 / 查询词数`，几十个词的查询让覆盖率趋近于零。
查询越"精确"，取到的证据越少——语义排序交给重排模型，召回只需给出一批候选。

## 3. 本轮踩到并修正的两个夹具陷阱

都不是产品缺陷，但都会让测试**看起来在验证、实际什么都没验证**：

### 3.1 测试 PDF 的内容流是 latin-1，中文会整体变成 `?`

`make_text_pdf_file` 用 `/WinAnsiEncoding` + latin-1 写内容流。第一版 M10 夹具用中文语料，
解析出来的文本全是 `?`，索引词表里只剩文件名（`alpha` / `beta`），
于是检索查询（中文研究问题）**永远命中不了任何片段**，生成必然报"本节没有可用证据"。

排查过程值得记录：现象是"本节没有可用证据"，我先后怀疑过索引缓存、冻结配置、
`_resolve_index` 透传，最后打印词表才看到 `vocab sample: ['alpha', 'beta']`。

修法是让夹具语料与查询**同语言且可被文本层编码**：统一改用英文语料 + 英文研究问题，
并把这条限制写进夹具注释与走查脚本（走查里同样标注了"中文会变成 `?`"）。

### 3.2 只有 5—10 条证据，却给每个 block 分同一条证据

M04 网关会拒绝同一请求内的**重复引用**。第一版替身让每个 block 都引用
`evidence_ids[0]`，请求直接被网关拒掉。改为按序号各取一条不同证据。

   没有为 `disagreements` 单独筛选争议证据。
4. **真实模型输出未冒烟**：全部用替身。真实 `generate_sections` 的写作质量、
   引用合规率、五节覆盖度要等 M14。
5. **检索语言一致性是隐含前提**：生成用冻结研究问题做查询，语料与查询语言不同
   （例如中文问题 + 英文文献）时召回质量可能下降。没有相关证据的章节会明确说明覆盖限制，
   仍需人工区分语料确实缺乏信息与跨语言召回不足。
6. **人工抽检**：正文的学术合理性与引用恰当性只能人工判断。
