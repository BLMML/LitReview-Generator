## 本次修复

1. **默认模拟模型引用失配**：旧固定样例带有并不存在于当前 Run 的论文 / 证据 ID，触发 `MODEL_OUTPUT_INVALID`。新增 `backend/apps/llm/mock.py`，默认响应绑定实际请求的允许 ID；摘要与正文明确标注模拟，事实支持返回待审。用于异常校验的命名夹具保持原样。默认 mock 版本进入模型快照及缓存身份，避免继续命中旧固定样例缓存。
2. **任务阶段与进度停留在 accepted / 0**：分析、检索、生成、核验和导出服务持续回写实际阶段和总量。成功收尾与资源发布使用同一事务；失败 / 取消保留实际完成量，发布异常时不会提前留下完成进度。
3. **终态仍展示已受理提示**：前端在任务成功、失败或取消后收起受理提示，避免与终态错误或成功信息并列。
4. **Word 版本记录孤立末页**：缩小版本记录的行距、字号和间距，保留全部审计信息；模板更新为 `docx-template-v2`。重新导出后由 11 页变为 10 页，逐页检查无乱码、文字重叠或孤立的最后两行。

以上未改写旧失败 Run；修复后新建分析验证。原有项目、PDF 和历史正文 / 导出保留。本次没有新增数据库迁移，也没有改动 API Key、价格或预算配置。
