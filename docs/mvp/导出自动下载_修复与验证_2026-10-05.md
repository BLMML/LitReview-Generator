# 导出正文自动下载修复

日期：2026-10-05。问题：点击“导出正文”后看不到下载或明确反馈。

## 原因与实际记录

用户指定的手稿已核验通过，数据库中已有四份 `ready` Word，四次导出任务均 `succeeded`。旧页面按钮只受理生成任务，成功文件只能在长手稿底部的“历史导出”另点下载，受理反馈又位于页面顶部，点击位置看起来没有反应。

现有最新文件 `56064b67-2eb6-4559-aa2a-5b5d10dbed3f`：43,323 字节，授权下载 HTTP 200，MIME 正确；DOCX 压缩包、正文 XML 和 57 个段落可读取，固定主模块与子模块齐全，没有模拟草稿前缀。

## 改动

- 在原导出按钮旁显示提交、生成、下载进度及错误。
- 仅为用户明确发起的导出跟踪 Export 资源，生成后自动下载一次；打开历史页面不会批量自动下载旧文件。
- 同一正文、核验报告及警示条件已有 pending / ready 导出时，跟踪现有任务或直接下载成品。生成和下载中禁用重复点击。
- 下载失败可重新点击导出复用现成文件；保留历史导出的独立下载入口。
- 网络响应不确定时先按原幂等键确认提交，再交付文件，避免留下未解决的提交。
- 离开页面停止轮询并取消尚未完成的文件获取；历史列表刷新失败不取消已受理的下载跟踪。
- 后端核验、警示确认、版本绑定、所有权校验与费用记录保持原有规则。本次没有新增模型调用。

文件：`frontend/src/composables/exportDelivery.ts`、`pages/ReviewPage.vue`、`components/ValidationPanel.vue`、`api/resources.ts`；同步更新 README 和用户说明书。

## 使用

已保存的手稿可刷新页面，再点“导出正文 vN ↓”；按钮旁将显示生成或下载进度，Word 成品会自动下载。浏览器若要求允许下载，按它的提示操作。之前的文件也可从“历史导出”下载。
