# 手稿原句选择修复与真实验证

日期：2026-10-05。对应“测试：本体与理论体系之问（"是什么"）”项目在生成“研究思路”时出现的 MODEL_OUTPUT_INVALID。

## 失败原因

任务 ef8e7b6e-95e6-4931-a738-751ffa0bcb6d 使用真实 deepseek-flash。原文模块同时接收 PDF 摘录与旧分析摘要，模型混用了摘要中的概括性文字；一次修复调用仍有非原文描述。严格 PDF 原文校验正确拒绝了这些块，因此在 1/8 停止，未发布部分正文。不是 token 上限或 Redis 连接问题。

## 修复

- 生成版本提升为 review-gen-v6-source-selection，冻结 pdf-passage-selection-v1。
- 每节由 PDF 完整原句建立目录，编号绑定策略、证据 ID 与原句全文。模型只选择 source_passage_id；后台填入对应原文和唯一证据，再验证完整句子及真实页段行。拒绝未知、重复、跨本节目录的编号，以及携带替换正文或引用的选择块。
- 移除旧分析摘要；原文模块依据 PDF，自主述评依据前文已采用的原文。保留八槽顺序、缺失说明和自主述评规则。新编号不进入保存的正文、前端或 Word。
- 历史完整正文输出仍兼容，但继续严格拒绝改写、半句话及无效出处，不用模糊匹配将错误文字替换成“相近原文”。
- 每次生成前计算剩余全文块数，预留后续模块及述评所需空间，保持全文 100 块上限。
