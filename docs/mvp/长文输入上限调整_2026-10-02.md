# 长文输入上限调整

日期：2026-10-02。用户最初要求两万字，随后追加要求：修改保守 token 上限，支持约三万字论文阅读。

`LLM_MAX_INPUT_TOKENS` 最初从 **24000** 调整为 **256000**，本次再提高为 **384000**，统一修改 `backend/config/settings.py` 的默认值、`.env.example` 和本机被忽略的 `.env`。`LLM_MAX_OUTPUT_TOKENS=4096`、模型模式、密钥、价格、项目金额预算和并发不变。

## 依据与边界

网关将完整系统 Schema、用户提示词的 UTF-8 字节数加 256 封装余量作为保守 token 上界；三万普通中文字本身约 90000 字节，随后还要加入证据片段元数据、UUID 白名单和提示词。单篇抽取之外，同主题争议比较会合并多篇全文。原 256000 已能容纳此次常规三万字样例；提高到 384000 给更多证据分片、元数据及双篇比较留下余量。

这不是将一个汉字当作三个实际计费 token。[供应商说明](https://api-docs.deepseek.com/quick_start/token_usage/)指出字符与 token 的换算只是估算，最终以 API usage 为准；应用仍按输入上界预留、实际 usage 结算。

当前配置模型为 `deepseek-flash`；2026-10-02 再次核对[官方模型说明](https://api-docs.deepseek.com/quick_start/pricing/)，上下文为 1M，384000 输入上界与 4096 输出上限留有上下文余量。本次没有更换模型、增加金额预算或调用付费 API。

验证覆盖正常证据包中的三万字单篇及双篇完整中文文本输入，不代表扫描转录准确性、供应商可用性或学术判断已验收。多篇全文合并可能继续超限；网关仍拒绝超限，不省略后半篇或静默截断。默认 PDF 25 MiB / 50 页限制不变。

图像请求目前预留整个部署输入上限；增大上限会增加此类请求的预算预留，余额不足仍返回 BUDGET_EXCEEDED。此前 24k 容量下的整轮费用估算不再代表当前最坏上界，不能通过放宽金额预算来自动绕过检查。
