# 学术文献综述智能生成系统 · 用户使用说明书

适用版本：`v0.12.0-m12-raw-workbench`  
更新日期：2026-10-05  
适用对象：通过浏览器管理文献、整理证据和撰写综述的用户。

导航：[快速上手](#1-第一次使用完成一份-word-草稿) · [文献管理](#5-收集和管理论文) · [文献分析](#6-分析文献) · [证据检索](#7-检索并核对证据) · [编辑与版本](#9-编辑正文引用与版本) · [核验](#10-核验正文) · [Word 导出](#11-导出与下载-word) · [任务处理](#12-任务取消与重试) · [常见问题](#14-常见问题)

本系统的使用顺序是：**创建项目 → 收集文献 → 分析 → 回看证据 → 生成综述 → 人工修改 → 核验 → 导出 Word**。

本机现已按用户授权启用**真实模型模式（real）**，新模型任务会发送选定资料给已配置的 DeepSeek 服务，并在项目预算内计费。新安装默认仍为模拟模式（mock），仅供流程测试；模拟摘要、主题和空缺项不能作为真实学术结论。切换模式不会改写旧分析或旧手稿，正式分析需新建真实分析快照；arXiv 导入在两种模式下均需要网络。

## 1. 第一次使用：完成一份 Word 草稿

1. 打开 [用户工作台](http://127.0.0.1:5173)，使用管理员提供的用户名和密码登录。
2. 点击 **“+ 新建研究项目”**，填写项目名称和研究问题，点击 **“创建项目 →”**。
3. 在 **“01 / 文献”** 上传两份 PDF，检查两篇是否都是 **“已纳入”**。
4. 点击 **“开始分析文献 →”**，等待任务完成，分析快照显示 **“已就绪”**。
5. 在 **“02 / 分析”** 查看要素与摘要，点击证据核对原文。
6. 在 **“03 / 证据”** 输入问题，点击 **“检索证据 →”**，查看相关片段。
7. 在 **“04 / 手稿”** 填写综述标题和目标字数，点击 **“生成综述 →”**。
8. 生成完成后打开手稿，修改正文与引用，点击 **“保存为新版本 →”**。
9. 点击 **“核验正文 vN →”**，等待核验完成；根据报告核对和修改内容。
10. 满足导出条件后，阅读并按需确认警示，点击 **“导出正文 vN ↓”**；在 **“历史导出”** 点击 **“下载 Word ↓”**。

这里的 `vN` 表示你当前选择的正文版本。例如，首次生成通常是 `v1`，第一次人工保存后是 `v2`。

## 2. 使用前准备

### 2.1 账号和访问地址

| 入口       | 本机地址                       | 用途                     |
| ---------- | ------------------------------ | ------------------------ |
| 用户工作台 | <http://127.0.0.1:5173>        | 日常使用入口             |
| 登录页     | <http://127.0.0.1:5173/login>  | 输入用户名与密码         |
| 管理后台   | <http://127.0.0.1:8000/admin/> | 管理员创建账号、维护配置 |

这些地址适用于当前本机开发环境；部署到服务器后使用管理员提供的地址。普通用户使用工作台即可，无需管理后台权限。

系统目前没有公开注册和自助找回密码。没有账号或忘记密码时，请联系管理员。不同账号的项目和原始文件分别授权访问。

若页面无法打开，请让管理员按照 [README 的快速启动步骤](../README.md#快速启动) 检查服务。直接访问本机 `http://127.0.0.1:8000/` 出现 404，不代表用户工作台故障；本机工作台入口是 5173。

### 2.2 准备文献

优先使用能正常打开、能复制正文文字的 PDF。扫描件或复杂图片页面依赖图像辅助能力，当前默认模拟模型不会识别图片中的文字；这类文件可能解析失败。

| 项目           | 当前限制或要求                                   |
| -------------- | ------------------------------------------------ |
| PDF 文件       | 每份不超过 25 MiB、50 页；不接受加密或损坏的文件 |
| 项目文献数     | 当前论文账本最多 30 篇                           |
| 开始分析       | 纳入 2—30 篇论文                                |
| arXiv 批量导入 | 每次 1—10 个 ID                                  |
| 项目名称       | 最多 120 字符                                    |
| 研究问题       | 5—2000 字符                                      |
| 检索问题       | 2—2000 字符                                      |
| 综述目标字数   | 2000—4000 字，是写作目标，不保证精确达到         |
| 正文编辑       | 每块 1—600 字符；每节至少 1 块；全稿最多 100 块  |
| 每块引用       | 最多选择 20 条原文证据；“主张”块至少需要 1 条    |

论文输入容量与综述输出字数分别控制。读取一篇三万字论文，并不意味着可以生成三万字综述；单篇全文及提示词、主题汇总或两篇必要比较依据仍可能触发输入上限，系统不会自动截掉超限正文。

## 3. 认识工作台

登录后首先看到 **“项目档案”**。点击项目卡片进入研究工作台；点击顶部 **“项目档案”** 可以返回项目列表。

| 工作台入口    | 可以做什么                                             |
| ------------- | ------------------------------------------------------ |
| **01 / 文献** | 上传、导入、编辑元数据、纳入或取消纳入、删除、阅读 PDF |
| **02 / 分析** | 查看单篇要素、摘要、年份统计、研究主题和争议对照       |
| **03 / 证据** | 检索本次分析的证据，按论文及页码浏览原文片段           |
| **04 / 手稿** | 生成综述，打开已经生成的手稿                           |
| **历史记录**  | 查看任务进度、失败原因、取消与重试入口                 |
| **分析历史**  | 选择不同时间建立的分析快照                             |

右侧的原文区域会显示证据片段和 PDF 页面。在较窄屏幕上，原文区域可能排列在内容下方，向下滚动即可查看。

## 4. 登录与创建项目

### 4.1 登录和退出

1. 在登录页填写 **“用户名”** 和 **“密码”**。
2. 如需检查输入，可点击 **“显示”**；确认后可切换为 **“隐藏”**。
3. 点击 **“登录，打开手稿 →”**。
4. 使用结束后，点击顶部 **“退出登录”**。

登录过期时按页面提示重新登录。退出前先保存手稿；如果存在未保存改动，页面会要求确认是否放弃。

### 4.2 新建项目

1. 在项目档案点击 **“+ 新建研究项目”**。
2. 填写项目名称，例如“社会治理与五社联动文献综述”。
3. 填写明确的研究问题，例如“社会工作与志愿服务在五社联动中如何协同促进基层社会治理？”
4. 点击 **“创建项目 →”**，系统进入该项目工作台。

当前输出语言为中文。研究问题越明确，越便于判断选文和引用是否与项目相关。

点击工作台顶部 **“修改项目问题”** 可以调整项目信息。已有分析不会自动更新为新问题；修改后请根据过时提示重新分析。

### 4.3 删除整个项目

1. 返回 **“项目档案”**，找到需要移除的项目。
2. 如需保留 PDF 或 Word，先进入项目下载所需文件。
3. 点击项目卡片中的 **“删除项目”**，核对确认窗口中的项目名称和影响范围。
4. 点击 **“保留项目”** 或按 Esc 可以取消；确定移除时点击 **“确认删除项目”**。
5. 成功后项目卡片消失，列表中的项目数量更新；刷新后仍不会显示。

此操作移除整个项目，包括该项目的论文、分析和综述手稿的工作台访问。删除后，旧项目链接、原文和 Word 下载链接均不可继续使用；系统保留底层文件、历史和费用账本，当前界面没有项目恢复入口。它与第 5 节的“删除论文”不同，重新上传同一论文不能恢复整个项目。

项目有排队、执行中或正在取消的任务时，删除按钮不可用；先进入历史记录等待完成或正常取消。若确认期间项目或文献发生变化，删除会被版本检查拒绝，请点击“重新读取项目”后再次核对。

## 5. 收集和管理论文

### 5.1 上传本地 PDF

1. 打开 **“01 / 文献”**，找到 **“收集论文”**。
2. 在 **“本地 PDF”** 选择文件。
3. 可填写 **“论文标题（可选）”**；留空时使用文件名。
4. 点击 **“上传论文 ↑”**。
5. 上传成功后，在 **“论文账本”** 查看文件标题、页数和纳入状态。
6. 上传下一篇时重新选择文件，再提交。

上传成功表示文件已进入账本；要素抽取和主题整理要等到分析任务完成。系统会检查文件格式、页数和大小，同一项目重复上传同一文件不会无条件新增一条论文。

### 5.2 导入 arXiv 文献

1. 在 **“arXiv ID”** 输入文献 ID，例如格式 `2401.12345v2`；请填写实际需要导入的 ID。
2. 一行一个，也可用空格、逗号或分号分隔；每批最多 10 个。
3. 点击 **“导入 arXiv →”**。
4. 在 **“历史记录”** 逐项查看“已导入”“已有论文”或“导入失败”。

此入口接收 arXiv ID，不接收任意网址。部分条目失败时，已成功导入的论文会保留；先处理失败原因，再使用当前任务提供的重试入口。

### 5.3 补全标题、作者和年份

1. 找到论文，点击 **“编辑元数据”**。
2. 修改标题；多个作者用分号分隔。
3. 填写年份；不知道时可以留空。
4. 点击 **“保存元数据”**。

元数据用于分析统计、快照和参考文献。建议在分析前尽量补全，避免作者或年份显示为未知。

### 5.4 纳入、取消纳入与删除

| 操作           | 操作方法                                           | 结果                                       |
| -------------- | -------------------------------------------------- | ------------------------------------------ |
| 纳入论文       | 点击 **“纳入分析”**                                | 进入下一次分析的选文集合                   |
| 暂时不使用     | 点击 **“取消纳入”**                                | 保留在账本，下一次分析不使用，仍占文献名额 |
| 删除论文       | 点击 **“删除论文”**，核对标题后点击 **“确认删除”** | 移出当前账本，释放文献名额                 |
| 取消删除操作   | 在确认窗口点击 **“保留论文”**                      | 论文继续留在账本                           |
| 恢复已删除论文 | 重新上传同一 PDF，或再次导入相同来源的 arXiv 文献  | 恢复原论文记录，仍需满足项目容量限制       |

删除会保留历史分析、已有综述的引用和原始 PDF，不是物理销毁文件。当前界面没有回收站或“彻底删除原始文件”入口。

修改元数据、纳入集合或删除论文后，已有分析可能显示 **“语料已过时”**。历史仍可阅读，需要新检索或新综述时重新分析。

### 5.5 阅读原文

点击论文旁的 **“阅读原文 ↗”**。在原文区域使用左右箭头翻页，或输入页码跳转；点击 **“下载原始 PDF ↓”** 可保存原文件。

## 6. 分析文献

### 6.1 启动分析

1. 确认需要使用的论文都显示为 **“已纳入”**，2—30 篇。
2. 点击 **“开始分析文献 →”**；已有分析时按钮显示为 **“重新分析文献 →”**。
3. 查看任务面板或 **“历史记录”** 的阶段和完成量。
4. 等待任务显示 **“已完成”**，并确认 **“分析快照”** 为 **“已就绪”**。

一次分析最多纳入 30 篇文献，系统逐篇解析和提取要素，再分批归纳主题并汇总全部文献。同主题争议比较会覆盖全部成员及跨批次论文组合，不再只取前 8 篇。没有依据的文献会明确记为未归类；没有争议时不会强行生成。失败后重试保留已完成的单篇分析。

分析会记录当时的研究问题、论文和证据，形成一次固定的分析快照。以后修改项目资料不会覆盖这次记录。

**“任务已受理”表示已进入后台处理，不等于分析完成。** 处理期间，同一项目的资料修改和新任务通常暂不可用，可以继续阅读原文与历史结果。

### 6.2 查看结果

在 **“02 / 分析”** 查看已解析数量、失败数量、论文年份和逐篇状态。

- **“要素与摘要”**：查看研究问题、研究对象、方法、数据集、指标、结论、局限与摘要。
- **“证据 N ↗”**：查看支撑该项内容的原文片段。
- **“按页查看证据 →”**：转到证据页，浏览论文中的片段。
- **“研究主题”**：查看主题描述、归属论文和相关依据；一篇论文可以属于多个主题。

“未提取到该项”或“本次分析没有形成争议记录”不等于原论文一定没有相关内容，仍应对照原文判断。模拟模式下只提供流程验证用的摘要、主题和空缺项。

### 6.3 复核争议

若 **“争议对照”** 有记录：

1. 阅读左右两篇论文的主张、适用条件和可比性说明。
2. 点击双方 **“原文 N ↗”**，核对证据是否支持显示的主张。
3. 在 **“人工复核备注”** 写下依据。
4. 点击 **“确认”**、**“拒绝”** 或 **“标记待复核”** 保存判断。

“确认”是记录你对该争议候选的判断，不是自动判定一方正确。复核变更会更新分析版本；基于旧分析的手稿可能提示过时，继续写作时应基于当前分析生成新手稿。

### 6.4 处理部分失败

若出现“文献处理失败，成功产物已保留”，先在逐篇分析账本查看哪一篇失败，再到历史记录查看错误原因。不要仅根据已解析数量判断整个分析已完成；是否可生成以快照的就绪状态为准。

按页面允许的方式重试。若已经修改论文、研究问题或模型配置，应重新分析建立新快照；刷新页面不会重新执行旧失败任务。

## 7. 检索并核对证据

### 7.1 用问题检索

1. 选择当前、已就绪的分析快照，打开 **“03 / 证据”**。
2. 在 **“在本次分析快照中检索”** 输入问题，例如“社会工作者与志愿者如何分工协作？”
3. 点击 **“检索证据 →”**，等待任务完成。
4. 展开 **“检索记录”**，点击结果的原文入口，核对片段和页码。

检索范围是当前选中的分析快照，不是互联网或全部项目。检索分数表示相关性，不代表结论正确，也不代表证据已经通过人工核对。

### 7.2 按页浏览

1. 找到 **“按原文页选择证据”**，选择 **“快照论文”**。
2. 输入原文页码；留空时浏览该论文的证据列表。
3. 点击 **“读取证据”**。
4. 点击片段旁的页码入口，在原文区域查看完整页面。

页码按 PDF 文件中的页面顺序计算，可能与论文印刷页码不同。当前阅读器定位到页面，不提供句子高亮。

证据标记的含义：

| 标记           | 含义                                             |
| -------------- | ------------------------------------------------ |
| 文字匹配       | 片段来自匹配的原文文字；不代表它一定支持当前论点 |
| 图像证据待核对 | 图像转录内容需要与 PDF 页面人工比对              |
| 人工核对标记   | 记录中的人工核对状态；仍需结合引用用途判断       |

## 8. 生成综述手稿

1. 选择当前、已就绪且未过时的分析快照。
2. 打开 **“04 / 手稿”**，找到 **“写一份综述”**。
3. 填写 **“综述标题”**；留空时使用项目名称。
4. 填写 **“目标字数”**，当前范围为 2000—4000，默认 3000。
5. 点击 **“生成综述 →”**，等待任务完成。
6. 在 **“手稿档案”** 点击该手稿，进入编辑页。

综述严格按 **研究背景 → 研究思路 → 研究意义 → 文献综述（理论基础 → 国内外研究现状）→ 文献述评（已取得的成果 → 文献的不足之处 → 本文创新点）** 排列。核心模块与子模块的标题、顺序固定，不可增删或改名。前四个主模块没有对应素材时，该模块只显示 **“提供的素材中没有该内容。”**。

前四个主模块只选取能完整定位的原句或原段；系统排除 PDF 页尾、证据边界及可能跨页续接的半句话。模型选择原句编号，后台填入对应 PDF 原文与出处，旧分析摘要不会作为原文输入。编号或正文校验失败时最多修复一次，仍失败会在历史记录显示具体模块和原因。更新后遇到旧失败记录，请从工作区重新生成；旧记录会保留。

如果原文模块均为缺失说明，先核对模型模式：mock 只识别少量明确标题，不能据此判断论文没有内容。配置真实模型后从工作区重新生成手稿，旧空白版本保留。

文献述评基于前文进行自主分析：总结既有成果，在“文献的不足之处”逐个讨论至少两个有依据的学术争议、不同观点的合理性与局限及成因，在“本文创新点”提出研究空白、未来方向与拟开展的创新思路。争议材料不足时不编造内容，允许导出带“争议证据不足”说明的述评草稿。新规范需重新生成手稿，旧版本与已导出的文件保留。

目标字数是写作目标，证据不足时正文可能更短；模拟模式也不保证达到目标。生成完成只表示首个正文版本已保存，不代表事实核验或学术质量已经通过。

如果按钮不可用，检查：项目是否有任务进行中、分析是否已就绪、选中的分析是否过时。

## 9. 编辑正文、引用与版本

### 9.1 修改正文

1. 在 **“正文版本”** 选择最新版本。
2. 前四个主模块采用完整原句或原段，不添加主观评价或素材外信息；文献述评基于前文依据自主分析。固定模块标题不可修改。
3. 需要增加段落时点击 **“+ 添加正文块”**；需要移除段落时点击 **“删除块”**。
4. 确认所有块都有内容，每节至少保留一块。
5. 点击 **“保存为新版本 →”**，看到“已保存正文 vN”后确认版本号增加。

编辑器不会自动保存。页面上的 **“有未保存改动”** 表示内容仍未提交；离开、刷新或切换正文版本前先保存。

历史正文只读。想继续修改时，点击 **“打开最新版本”**。保存生成新版本，旧版本仍保留，不会被覆盖。

### 9.2 选择块类型和引用

| 块类型          | 用途                           | 引用要求                                   |
| --------------- | ------------------------------ | ------------------------------------------ |
| 原文正文 / 需要证据 | 采用 PDF 原文完整句子或段落 | 每块恰好选择 1 条来自该手稿快照的证据 |
| 自主述评 / 需要前文依据 | 分析成果、争议、成因、空白及研究建议 | 每块 1—20 条，必须是前文原文模块已引用的证据 |
| 缺失说明 | 仅填写“提供的素材中没有该内容。” | 无引用，该模块只保留这一块 |

述评块选择对应的“分析内容”；争议对比与成因还需填写“争议编号”，同一争议使用同一编号。拟开展的创新不等于已经取得的成果，原因推测要明确尚待验证。

缺失说明不需要引用，编辑器会固定提示文字并禁用选证据。找到材料后，先把块类型切换为“原文正文 / 需要证据”，再填写完整原文并选择引用；也可点击“+ 添加正文块”替换该模块的单块缺失说明。

添加引用的步骤：

1. 在对应正文块点击 **“+ 选择原文证据”**。每块只对应一条证据，更换时先移除原引用。
2. 在 **“为当前块选证据”** 选择论文，按需填写页码。
3. 点击 **“读取证据”**，阅读片段；可先点击页码核对 PDF。
4. 点击 **“加入此块 +”**，或在原文区域点击 **“把这条证据加入当前块 +”**。
5. 点击块下方 **“引用 N ↗”** 回看证据；引用旁的 **“×”** 可以移除该引用。
6. 修改完成后保存新版本。

引用从本手稿所属的分析快照中选择，不能通过直接输入参考文献编号替代。添加引用时也要检查证据实际支持的是哪一部分表述。

### 9.3 保存冲突时保留草稿

如果提示内容已被其他操作修改：

1. 先把重要的未保存文字复制到本地文件。
2. 点击 **“重新读取服务器版本（保留草稿）”**，查看服务器最新版本信息。
3. 核对最新版本，再人工整理需要保留的修改。
4. 从最新正文版本重新保存。

系统不会自动合并冲突。切换到其他正文版本可能要求放弃未保存改动，确认前先做好文字备份。

## 10. 核验正文

1. 确认编辑已保存，选择需要核验的 **“正文版本”**。
2. 在 **“核验与导出”** 点击 **“核验正文 vN →”**。
3. 等待核验任务显示 **“已完成”**。
4. 在 **“此版本的核验报告”** 选择报告，检查结构结果和逐块意见。
5. 点击 **“定位正文与引用 →”**，回到需要处理的正文块。

核验意见包括：

| 意见       | 处理建议                                   |
| ---------- | ------------------------------------------ |
| 原文支持   | 仍需核对表述范围、适用条件和原文语境       |
| 原文不支持 | 修改主张或更换证据，保存后重新核验         |
| 无法确定   | 对照全文人工检查，补充依据或收窄表述       |
| 不适用     | 通常对应组织行文的过渡内容                 |
| 结构问题   | 按具体问题修正块、章节或引用，再保存和核验 |

**核验报告只绑定一个已保存的正文版本。** 把 `v2` 改成 `v3` 后，需要重新核验 `v3`，不能用 `v2` 的报告导出新正文。

`needs_review` 表示仍需人工审阅，不等于后台任务失败。默认模拟模型不会作出真实事实支持判断，因此出现“无法确定”和 `needs_review` 是预期结果。即便真实模型报告为通过，导出的文件仍是需要人工审阅的草稿。

## 11. 导出与下载 Word

### 11.1 导出条件

必须使用最新固定框架（含文献述评），并同时满足以下条件：正文已保存、核验报告属于当前选中的正文版本、核验任务成功、结构检查通过。

不足两个完整且通过核验的争议时仍允许导出，Word 会在“文献的不足之处”中自动显示“争议证据不足”及述评草稿说明；不出现“模拟草稿（需人工审阅）：”。原文出处采用 PDF 文件的页、段、行，述评出处表示分析依据。

存在 **“有未保存改动”**、尚未完成核验、核验失败或结构未通过时，先解决这些问题。

### 11.2 导出步骤

1. 选定要导出的正文版本，以及该版本的成功核验报告。
2. 阅读 **“导出将携带以下警示”**。警示可能包括待审问题、语料过时、分析过时或导出历史正文。
3. 若存在警示且仍决定导出，勾选 **“我已阅读这些警示，仍要导出此版本”**。
4. 点击 **“导出正文 vN ↓”**，按钮旁显示生成和下载进度；任务完成后自动开始下载 Word，无需滚到整篇手稿底部。
5. 查看浏览器下载记录。同一正文、核验和警示条件已有可下载文件时，再点导出按钮会直接下载现有文件，不重复创建导出任务。
6. 若按钮旁显示生成或下载错误，按提示再次点击导出。页面底部的 **“历史导出” → “下载 Word ↓”** 仍可用于下载之前的文件。

确认警示不会消除警示，也不会把待审结果改成通过。切换版本、报告或警示条件后，需要重新阅读并确认。

Word 正文只包含文章标题、固定研究框架、原文表述及出处；不显示“模拟草稿（需人工审阅）：”，不另列原文、证据附录、参考文献、版本记录或核验警示。警示与核验结果仍可在工作台查看，审计信息保留在后台和文档属性中。

出处格式为 **《PDF 文件名》第 N 页，第 N 段，第 N 行**，跨行时标注行范围。页码是 PDF 的实际页面序号；段号由文本层版面按阅读顺序识别，每页从 1 计数，行号在段内从 1 计数。双栏、缩进或复杂排版仍需回看 PDF 核对；只有图片或无法可靠定位的内容不能伪造段行出处。

旧章节结构的手稿仍可阅读。要导出本次固定研究框架，请返回项目重新生成综述，核验新版本后导出。

Word 下载后在本地修改，不会自动同步回系统。若要让新的修改继续参与核验，请回到系统编辑、保存新版本，再核验和导出。

### 11.3 查看历史导出

每条导出记录对应固定的正文和核验版本，可在 **“核验绑定与任务”** 查看关联编号。

导出失败且页面提供重试入口时，可在处理原因后点击 **“重试导出”**。若重试提示出现新的警示，重新选定正文与核验报告，阅读警示后发起一次新导出。

## 12. 任务、取消与重试

| 任务状态 | 含义与操作                                           |
| -------- | ---------------------------------------------------- |
| 排队中   | 请求已受理，等待后台处理；不要反复提交               |
| 执行中   | 正在处理，可查看阶段和完成量                         |
| 正在取消 | 已提出取消请求，等待安全收尾；暂不能立即新建互斥任务 |
| 已完成   | 本次任务成功；查看对应分析、正文、报告或文件         |
| 失败     | 阅读错误信息；先处理原因，再使用允许的重试入口       |
| 已取消   | 本次执行已结束；是否继续以页面提供的操作为准         |

取消时点击 **“取消任务”**，等待状态变成 **“已取消”**。取消不是删除任务记录，也不保证撤销已经发生的模型调用或费用；已成功阶段的产物可能保留。

失败可重试或任务已取消时，页面会提供 **“重试任务”**。重试通常恢复允许恢复的已完成阶段；只能继续最新一次尝试，材料已经过时时可能需要重新分析。

网络中断导致进度读取失败时，点击 **“重新连接”** 或历史记录的 **“重新读取”**。刷新、关闭页面或退出登录不会自动取消已经提交的后台任务。手稿未保存时先备份文字再刷新。

任务面板显示状态、阶段、进度和错误，不显示模型 token 用量、费用估算或未结算调用数。后端继续记录用量、控制预算并结算费用，需要核对时请联系管理员。

## 13. 历史记录与过时提示

| 记录            | 表示什么                             | 发生变化后怎么做                               |
| --------------- | ------------------------------------ | ---------------------------------------------- |
| 语料版本        | 当时的项目问题、论文元数据与纳入集合 | 改动资料后重新分析，历史原文仍可回看           |
| 分析快照        | 某次分析固定使用的资料和结果         | 在“分析历史”切换；旧快照不会自动变成新结果     |
| 分析版本        | 该快照中主题、争议复核等分析状态     | 旧手稿可能过时，继续写作时基于当前分析生成新稿 |
| 正文版本        | 某次生成或人工保存的完整正文         | 修改后保存新版本，重新核验                     |
| 核验 / 导出记录 | 绑定的正文及核验结果                 | 对照绑定版本查看，不覆盖旧文件                 |

显示 **“语料已过时”** 时，可以查看已有分析、证据和检索记录；新检索与新综述需要当前语料的就绪快照。

显示 **“此正文基于历史分析版本”** 时，单纯修改或保存旧正文不会消除过时状态。需要继续基于新资料写作时，完成新的分析并生成新手稿。

历史正文可在满足核验与警示确认条件时导出，但文件会保留对应警示。

## 14. 常见问题

| 问题或提示                       | 原因与处理                                                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 没有账号或忘记密码               | 请管理员创建账号或重置密码，当前没有自助注册 / 找回入口                                                                  |
| 上传成功，但没有摘要             | 上传与分析是两个步骤；至少纳入两篇后开始分析                                                                             |
| 已有两篇论文，分析按钮仍不可用   | 检查是否都已纳入，以及项目是否有任务尚未结束                                                                             |
| 修改、删除或生成按钮变灰         | 常见原因是项目任务执行中；查看历史记录，等待或正常取消                                                                   |
| 旧快照显示失败，但资料已改好     | 旧记录不会随修改自动重跑；点击“重新分析文献”建立新快照                                                                   |
| 提示输入超过保守 token 上限      | 主题与争议比较已按请求大小自动分批；若单篇全文、汇总结果或两篇必要依据仍超限，联系管理员核对配置与失败阶段。系统不会截掉原文后继续   |
| `MODEL_OUTPUT_INVALID`           | 模型响应结构或引用未通过校验；记录任务和请求编号交给管理员。不要用反复提交绕过引用检查；旧失败分析可能需要修复后重新创建 |
| `PDF_PARSE_FAILED`               | 检查 PDF 是否能正常打开、是否损坏或缺少可用文本层；扫描件请先准备带文本层的版本或联系管理员检查图像辅助能力              |
| 预算不足 / `BUDGET_EXCEEDED`     | 联系管理员检查项目预算与记账；零预算不代表无限使用                                                                       |
| 检索结果为空                     | 调整关键词，核对是否选择了正确且已就绪的分析快照；也可按论文页码直接读取证据                                             |
| 核验成功却显示 `needs_review`    | 任务已执行成功，但内容仍需人工审阅；按逐块意见处理                                                                       |
| 导出按钮不可用                   | 检查正文是否保存、报告版本是否匹配、结构是否通过、核验任务是否成功，以及警示是否确认                                     |
| 提示 `WARNINGS_NOT_ACKNOWLEDGED` | 阅读当前版本警示，确认后重新发起导出；换版本后需重新确认                                                                 |
| 页码与论文印刷页码不一致         | 系统按 PDF 第几页定位；对照阅读器页面查看                                                                                |
| 删除后旧综述仍能打开原文         | 这是历史引用保留行为；删除仅将论文移出当前账本                                                                           |
| 输入内容保存失败或版本冲突       | 先复制未保存文字，再重新读取服务器版本，基于最新正文整理修改                                                             |
| 登录过期或 Word 下载失败         | 重新登录，进入对应项目与“历史导出”再下载；文件需要登录授权                                                               |
| 后台任务一直排队或停在受理阶段   | 先重新连接查看；若长期无进展，请管理员检查 Redis 和 worker 是否正常运行                                                  |

联系管理员时提供：项目名称、操作步骤、错误信息 / 错误码、任务编号、请求编号、发生时间。任务编号可展开 **“任务编号与时间”** 获取；请求编号在部分操作错误提示中显示。

## 15. 管理员：为用户创建账号

此节仅适用于已具备后台权限的管理员。

1. 打开 [管理后台](http://127.0.0.1:8000/admin/)，使用管理员账号登录。
2. 在用户管理中点击新增用户。
3. 填写用户名与密码并保存。
4. 按需填写姓名等信息，保持用户处于启用状态。
5. 普通工作台用户无需授予“工作人员”或“超级用户”权限。
6. 将账号和工作台地址交给该用户，由其从 5173 工作台登录。

忘记密码时由管理员在用户管理中重设密码。系统保存的是密码哈希，不能从数据库还原原密码。

当前用户界面没有模型密钥、价目或项目预算设置页。服务启动和真实模型配置由管理员按照 [项目 README](../README.md) 操作。
